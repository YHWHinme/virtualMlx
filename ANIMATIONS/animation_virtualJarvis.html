SpeechRecognition — the ears

The only way user input enters the system. Blocks the entire main thread until speech is captured.

sr.Recognizer() opens the default microphone and uses energy-based voice activity detection — not a neural network, just a simple amplitude threshold. It listens until the energy drops below the calibrated noise floor for a brief period, then returns the entire utterance as an AudioData object. This is sent to Google's API in the next stage.

# stt.py — the entire STT pipeline
def recordAudio():
  recorder = sr.Recognizer()
  with sr.Microphone() as source:
    recorder.adjust_for_ambient_noise(source, duration=0.2)
    audio = recorder.listen(source) # ← BLOCKS until speech ends
    text = recorder.recognize_google(audio) # ← HTTP to Google
    return text

Google Cloud STT — internet required

The transcription happens in Google's cloud — no offline fallback in the main path.

recognize_google() encodes the AudioData, sends it over HTTPS to Google's Speech Recognition API, and returns the transcribed text. This is the same API that powers Android's voice input. It's free for limited use but requires an active internet connection. If the network is down or Google rejects the audio, the error is caught and the loop retries.

importance 9 / 10 remote LLM

Ollama — the brain (remote server)

The transcript is sent to an Ollama server on the local network running Gemma 3 4B. The ollama Python package is just an HTTP client — the actual model runs on a separate machine. Two modes: blocking (full response) and streaming (chunk-by-chunk yield).

ollama.Client(host=...) client.chat(model, messages) client.chat(..., stream=True) gemma3:4b
LLM response — token-by-token streaming to Ollama server
# ollama_model.py — remote LLM client
client = Client(host="http://172.16.5.39:3000")

# Blocking mode
def ollama_chat(content):
  response = client.chat(model='gemma3:4b',
    messages=[{'role':'user', 'content': content}])
  return response

# Streaming mode — yields chunks as they arrive
def ollama_chat_stream(content):
  response = client.chat(model='gemma3:4b', ..., stream=True)
  for chunk in response:
    yield chunk['message']['content']

Kokoro — the voice

KPipeline combines text-to-phoneme conversion and phoneme-to-audio generation. It yields (graphemes, phonemes, audio) tuples. The audio chunks are accumulated, converted to a torch tensor, written to a WAV file via soundfile, then played back through ffplay (an external process).

KPipeline(lang_code='a') pipeline(text, voice='af_heart') torch.tensor(audio) sf.write(file, audio, 24000)
TTS synthesis pipeline — text → phonemes → audio → file
# tts.py — Kokoro pipeline + file playback
pipeline = KPipeline(lang_code='a') # US English

def speakText(input_text):
  all_audio = []
  generator = pipeline(input_text, voice='af_heart')
  for i, (gs, ps, audio) in enumerate(generator):
    all_audio.extend(list(audio))

  all_audio = torch.tensor(all_audio)
  sf.write(filename, all_audio, 24000) # write WAV to disk
  os.system(f"ffplay {filename} -autoexit -nodisp") # shell out
  os.remove(filename) # delete after playback

ffplay / PyAudio — two output paths

main.py shells out to ffplay. test_pyaudio.py streams directly to hardware.

The production path writes audio to a WAV file on disk, spawns an external ffplay process, waits for it to finish, then deletes the file. High latency, no interrupt capability. The test harness uses PyAudio for direct hardware streaming in 1024-sample frames (~42ms at 24kHz), enabling true concurrent playback.

Streaming — three-thread pipeline

# test_pyaudio.py — the real streaming architecture
text_queue = queue.Queue()
audio_queue = queue.Queue()

def ai_producer():      # Thread 1: LLM → text_queue
  for chunk in chunk_generator:
    buffer += chunk
    if is_sentence_end(buffer):
      text_queue.put(buffer)
  text_queue.put(None) # sentinel

def tts_consumer():     # Thread 2: text_queue → audio_queue
  while True:
    text = text_queue.get()
    if text is None: audio_queue.put(None); break
    audio_queue.put(generate_audio(text))

def playback_consumer(): # Thread 3: audio_queue → speakers
  stream = py_audio.open(rate=24000, output=True)
  while True:
    data = audio_queue.get()
    if data is None: break
    stream.write(data.tobytes())
